# Archívum

Ez a könyvtár a már nem aktív, de történeti vagy tanulási szempontból értékes állapotok helye.

Archiválni mérföldkövenként érdemes, nem minden munkamenet után. Ide kerülhet például:

- korábbi globális fókusz összefoglalója;
- lezárt tanulási szelet bizonyítékainak indexe;
- tömörített régi sessionnapló;
- felváltott, de indoklással megőrzendő módszertani döntés.

Az archívumot az agent nem olvassa be automatikusan. Csak akkor használja, ha az aktuális állapotból hiányzik egy szükséges előzmény vagy ellentmondás tisztázandó.
