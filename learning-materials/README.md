# Tanulási anyagok

Ez a könyvtár a tanterv témáihoz kapcsolódó, ellenőrzött forrásokat és ajánlott olvasási útvonalakat tartalmazza.

Az itt található fájlok nem helyettesítik:

- a `software-engineering-curriculum.md` tudástérképét;
- a `LEARNING_STATE.md` globális pillanatképét;
- a projektek `MENTORING_STATE.md` végrehajtási állapotát;
- a gyakorlati implementációból és saját magyarázatból származó tudásbizonyítékot.

## Használat

- Először az adott témában megjelölt alapanyagokat olvasd el.
- A forrásokat kapcsold a felsorolt projektkísérletekhez; ne próbáld a teljes dokumentációt egyszerre feldolgozni.
- Az opcionális mélyítéshez csak akkor lépj tovább, amikor az alapmodell már működik a gyakorlatban.
- Elavult vagy hibás linket frissíts a meglévő témalapon, ne készíts párhuzamos listát.
